# Semantic LKN: Knowledge & Results

This directory contains the public-facing knowledge base, logic scripts, and reasoning traces for the **Semantic LKN** project. This folder is curated for users who wish to explore the semantic capabilities of the engine without interacting with the C++ source code.

## Contents

### 1. [euclid_book1_defs.lkn](euclid_book1_defs.lkn)
A unified knowledge script containing **Definitions 1-22 of Euclid's Elements (Book 1)**. This file represents the foundational geometric truths that the engine uses for its reasoning.

### 2. [euclidElements.lkn](euclidElements.lkn)
The Euclidean Elements logic script. It consolidates parts-of-speech, core geometric knowledge, logical rules, and formal Propositions into a single verifiable suite.

### 3. [preEuclid.lkn](preEuclid.lkn)
A knowledge script covering the pre-Euclidean foundations of geometry, from prehistoric bone tallies to Sumerian metrology and the ancient law of **Systasis**.

### 4. [UrWalking.lkn](UrWalking.lkn) & [ScriberWorking.lkn](ScriberWorking.lkn)
Scripts that map the City of Ur and simulate the administrative tasks of a Sumerian scribe, including land surveying, pathfinding, and ration distribution ratios.

### 5. [actual_output_trace.txt](actual_output_trace.txt)
A complete execution trace showing the engine's responses to the logic suite. This file demonstrates real-world examples of **Deductive Subtyping**, **Complementary Inference**, and **Way of Logos** actualization for Propositions 1 and 2.

### 6. LKN_Historical_Foundation_Rod_and_the_Ring.md
The foundational document outlining the philosophical and historical underpinnings of the LKN Semantic project, tracing the "Rod and the Ring" duality from ancient Sumer to modern computational geometry.

### 7. LKN_On_Geo_Systasis.md
A deep dive into the **Systasis** layer—the invariant "Middle Ground" that bridges abstract notions and physical instances using a scale-invariant Web of Ratios (Analogia Plegma).

### 8. prop1_announcement.md
A focused look at the LKN encoding for Euclid's Proposition 1, detailing the **Logos State**, **Logos Path**, and the Aristotelian reasoning framework.

### 9. linkedin_announcement.md
The official milestone announcement. It provides an overview of the expansion from Euclid's logic to the streets of Ur and the achievement of a 193-test regression success.

## Purpose
These files serve as the "logical release" of the project. They can be fed into the LKN Semantic Engine to replicate the reasoning results shared in the project milestones.
